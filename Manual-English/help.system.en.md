### System

In the system settings, you can customize your username, select the language, change the joystick mode, restore factory settings, and update the firmware online.

　　

- **User and Language**: Customize username and select interface language.

- **Joystick Mode**: Change the system-level joystick mode. Options include **Mode 1-4**. New models will be created with this mode as the default.

- **Pre-flight Check**: This is a **system-level** function. Its **priority** differs from the pre-flight check in model settings, as it is a shared feature for **all models**. It allows setting **system-level** **power-on checks**, ensuring **low throttle** verification, default **switch position** checks, joystick **midpoint** checks, and joystick **center tone alerts** upon startup.

- **Restore factory settings**: Clear all settings and **reset to factory defaults**. Note that this option will **delete all models** and revert to the system’s preset **basic model** settings.

- **System & Firmware**: This function is used for **online** firmware updates.

- **Alarm votage:** Set the **low voltage** warning threshold for the remote control’s battery.
