### LUA

**LUA Plugin Functionality**: Supports the use of **third-party LUA script** plugins to enable certain feature extensions.

Third-party LUA script files should be placed in the root storage folder under the **AX12LUA** directory. Follow the requirements of the **LUA scripts** and place them in the **corresponding folders**. 

For example, **tool-type scripts** should be placed in the following folder path:

Internal Storage > AX12LUA > SCRIPTS > TOOLS
