### MainView

The default home page of the system, which includes basic information about the remote control.

　　

**Top Bar:**

<img title="" src="./image.en/img.main-view.2.png" alt="" data-align="center" width="500">

　　

- **Signal Strength**: After the remote control and receiver are paired and connected, the signal status and dBm value can be viewed.

<img title="" src="./image.en/img.main-view.3.png" alt="" data-align="center" width="100">

　　

- **Device Name**: The device name is displayed in the center and can be customized in the system settings.

<img title="" src="./image.en/img.main-view.4.png" alt="" data-align="center" width="300">

　　

- **Aircraft Voltage**: When using a receiver with voltage telemetry or a flight controller with voltage telemetry, the battery voltage of the aircraft can be displayed in real time.

<img title="" src="./image.en/img.main-view.5.png" alt="" data-align="center" width="80">

　　

- **Remote Control Voltage**: Displays the remote control voltage in real time.

<img title="" src="./image.en/img.main-view.6.png" alt="" data-align="center" width="80">

　　

- **Date**: Displays the current date.

<img title="" src="./image.en/img.main-view.7.png" alt="" data-align="center" width="110">

　　

**Home screen display:**

- **Joystick Position**: Graphical real-time display of joystick position, along with fine-tuning position display.

<img title="" src="./image.en/img.main-view.8.png" alt="" data-align="center" width="400">  

- **Model Name and Image**: Displays the current model name and image.

<img title="" src="./image.en/img.main-view.9.png" alt="" data-align="center" width="200">  

- **Timers T1/T2**: Displays T1/T2 timer durations. Tap the gear icon to access T1/T2 timer settings.

<img title="" src="./image.en/img.main-view.11.png" alt="" data-align="center" width="200">  　　

- **Channel Output**: Real-time display of CH01-CH08 channel outputs.

<img title="" src="./image.en/img.main-view.10.png" alt="" data-align="center" width="200"> 　　

- **Switches**: Real-time display of all switch positions.

<img title="" src="./image.en/img.main-view.12.png" alt="" data-align="center" width="200"> 　　

- **Knobs**: Real-time display of knob positions.

<img title="" src="./image.en/img.main-view.13.png" alt="" data-align="center" width="200">  　　

- **6-Position Switch**: Real-time display of the 6-position switch location.

<img title="" src="./image.en/img.main-view.14.png" alt="" data-align="center" width="200">

　　

****Bottom Bar:****

- **System Settings:** Enter system settings

<img title="" src="./image.en/img.main-view.15.png" alt="" data-align="center" width="100">

- **Model Settings:** Enter model settings

<img title="" src="./image.en/img.main-view.16.png" alt="" data-align="center" width="100">

- **Lock Screen:** Lock the screen to prevent accidental touches

<img title="" src="./image.en/img.main-view.17.png" alt="" data-align="center" width="100">

- **Home Screen:** Tap to return to the home screen

<img title="" src="./image.en/img.main-view.18.png" alt="" data-align="center" width="100">

- **Help:** There is a help icon on every page or in each function settings window. Tap it to display the instructions for the current function.

<img title="" src="./image.en/img.main-view.19.png" alt="" data-align="center" width="100">
